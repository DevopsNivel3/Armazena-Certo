# Frontend Web (Administrativo)

Painel administrativo para gestão de inventários.

## Instalação

1.  Instale as dependências:
    ```bash
    npm install
    ```

2.  Execute o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```

## Tecnologias

*   React
*   Vite
*   Tailwind CSS
*   Axios
*   Recharts
